# C# - Structs and Enumerations

This project introduces C# value types through a small `Dog` model:

- `0-dog`: declares the `Rating` enumeration.
- `1-dog`: declares the `Dog` structure and its public fields.
- `2-dog`: adds the `Dog` constructor.
- `3-dog`: adds the formatted `Dog.ToString()` representation.

Each numbered directory is a standalone SDK-style .NET project. The types are
intentionally declared in the global namespace so they can be consumed by the
course checker harnesses.
