# C# - Test Driven Development

Six solution-based exercises using class libraries and NUnit test libraries.

| Task | Method |
| --- | --- |
| `0-add` | `MyMath.Operations.Add(int, int)` |
| `1-divide` | `MyMath.Matrix.Divide(int[,], int)` |
| `2-max_int` | `MyMath.Operations.Max(List<int>)` |
| `3-palindrome` | `Text.Str.IsPalindrome(string)` |
| `4-unique` | `Text.Str.UniqueChar(string)` |
| `5-camelcase` | `Text.Str.CamelCase(string)` |

Each task has a solution file, a `netstandard2.0` class library with XML
documentation, and a `netcoreapp2.1` NUnit test project.
